# Inspect File Skill

This skill analyzes a file and provides useful insights such as size, line count, language, and content preview.

## Examples

- "Inspect this file: app.py"
- "Analyze the contents of README.md"
- "What is inside this file?"

## Instructions

```bash
python3 inspect_file.py <file>
```
