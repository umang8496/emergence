## Goals

By the end of this track you will be able to:

- derive and explain key models mathematically
- implement core algorithms from scratch
- choose suitable cost functions and optimizers
- diagnose convergence, overfitting, and class imbalance
- enter deep learning with solid intuition, not guesswork
